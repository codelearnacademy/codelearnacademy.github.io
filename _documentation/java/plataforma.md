    <h1>Plataforma Java</h1>

    <h2>JDK</h2>
    <p>El Java Development Kit proporciona las herramientas necesarias para desarrollar y compilar aplicaciones Java, incluido <code>javac</code>.</p>

    <h2>JVM</h2>
    <p>La Java Virtual Machine ejecuta el bytecode generado por el compilador. Esta capa permite distribuir el mismo programa compilado en diferentes sistemas compatibles.</p>

    <h2>JRE</h2>
    <p>En las distribuciones modernas, la ejecución se proporciona mediante el JDK o mediante un runtime específico. No debe asumirse la existencia de un instalador JRE independiente para cada versión de Java.</p>

    <h2>Versiones LTS</h2>
    <p>Java 8, 11, 17 y 21 son versiones con soporte a largo plazo. La versión objetivo debe fijarse explícitamente en el proyecto y comprobarse con las herramientas del JDK.</p>
