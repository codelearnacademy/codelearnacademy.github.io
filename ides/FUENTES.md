# Fuentes oficiales de la ruta

Estas páginas son las referencias principales para mantener actualizadas las instrucciones:

- Debian estable y netinst: https://www.debian.org/distrib/
- Guía Debian 13 trixie: https://www.debian.org/releases/trixie/installmanual.es.html
- OpenJDK 21 en Debian: https://packages.debian.org/stable/java/openjdk-21-jdk
- VirtualBox: https://www.virtualbox.org/
- VS Code Linux: https://code.visualstudio.com/docs/setup/linux
- VS Code Java: https://code.visualstudio.com/docs/languages/java
- IntelliJ IDEA: https://www.jetbrains.com/help/idea/installation-guide.html
- Eclipse IDE: https://www.eclipse.org/downloads/packages/
- Apache NetBeans: https://netbeans.apache.org/front/main/download/

Las versiones de los IDEs cambian con más frecuencia que Debian o Java. Las lecciones indican el producto y el método de instalación, y enlazan a la página oficial para consultar la release estable vigente.
