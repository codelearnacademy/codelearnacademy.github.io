    <h1>Comandos básicos de Java</h1>

    <h2>Comprobar la instalación</h2>
    <pre><code>java -version
javac -version</code></pre>

    <h2>Compilar y ejecutar</h2>
    <pre><code>javac Main.java
java Main</code></pre>

    <p><code>javac</code> genera bytecode en archivos <code>.class</code>; <code>java</code> inicia la ejecución de la clase indicada.</p>
