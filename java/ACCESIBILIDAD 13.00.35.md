# Accesibilidad de la ruta Java

La ruta debe poder utilizarse sin depender exclusivamente de la vista o del oído. Estas pautas se aplican al contenido y a las actividades.

## Imágenes y diagramas

- Todas las imágenes didácticas deben incluir un texto `alt` que describa el concepto, no solo el nombre del fichero.
- Ninguna explicación esencial debe existir únicamente dentro de una imagen.
- Los diagramas importantes deben acompañarse de explicación textual o código equivalente.
- No se debe utilizar el color como único medio para indicar correcto/incorrecto, estados o relaciones.

## Audio y vídeo

- Cualquier vídeo debe disponer de subtítulos y transcripción textual.
- Los ejemplos mostrados en vídeo deben ofrecer también el código fuente utilizado.
- Una señal sonora debe tener siempre un equivalente visual o textual.

## Código y navegación

- El contenido debe conservar una estructura jerárquica de encabezados.
- Los enlaces y controles deben poder utilizarse mediante teclado.
- Los bloques de código deben mantener un tamaño legible y permitir desplazamiento horizontal cuando sea necesario.
- Evitar instrucciones basadas únicamente en posición, forma o color como “pulsa el botón verde de la derecha”.

## Autoevaluaciones

- Las respuestas indican explícitamente “Respuesta correcta”; no dependen solo de verde/rojo.
- No se requiere límite de tiempo para responder.
- Las explicaciones deben poder ser leídas con lector de pantalla.

## Actividades

Cada actividad principal indica por escrito:

1. modalidad;
2. tiempo orientativo;
3. objetivo;
4. pasos o requisitos;
5. criterio de comprobación o entrega.

Esto reduce la dependencia de instrucciones verbales dadas en clase y permite volver a consultar el enunciado de forma autónoma.
